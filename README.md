## 🧩 Featured Project

### ADHDaily – Mobile Habit Tracker (Google Play)

A production Flutter application designed for people with ADHD to build and maintain daily habits in a minimal, distraction-free environment.

- Firebase Authentication (secure user accounts)
- Cloud database (Firestore)
- Habit tracking system
- Focus Timer for deep work sessions
- Thought Journal for mental clarity
- Subscription-based paywall system
